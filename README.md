# excel_to_CI-via-device-code-flow
These zip files are sample files which can demonstrate the excel to CI solution via Device Code flow. This approach is detailed and explained in the tutorial mentioned here- https://docs.oracle.com/en/learn/ociiam-excel-to-ci/#introduction
Please ensure to check the instructions /warnings before using these files.
These files are just for proof of concept and may need proper refactoring and an end-to-end functionality testing before marking it production ready.
The VB code is adjusted to follow the Device Code flow but we definitely recommend it to go through a VB expert for fine tuning and code quality check.
The sheets also have some opportunities for enhancements and those are captured in the tutorial.
